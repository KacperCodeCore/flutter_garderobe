# 👗✨📱 Flutter Garderobe Management App
This app helps you easily create and manage styles for any occasion.

## ✨ Features
Virtual garderobe organisation
Visually lay out your clothes in a virtual representation of your wardrobe, making it easy to find exactly what you need.

## Creative styling collections
Design unique styling combinations by dragging and positioning wardrobe items. Experiment with rotation, position, and scale to create the perfect look.

## Automatic styling snapshots
Each collection you create is automatically saved as an image — ready to be displayed on the homepage.

## Main gallery
View and manage all saved styling collections in a central Home gallery. You can easily view or edit any selected collection.
